Projects

Job Radar

A personal job search tool that finds new postings, ranks them, and shows them on a dashboard and through a Telegram bot so I can decide where to apply. It's built with Python and SQLite, a Next.js and React dashboard, and scheduled runs on my Mac plus a GitHub Actions job in the cloud, and it costs $0 a month to run. The biggest thing I learned was to test fixes under real load as one fix to the duplicate check made it run in quadratic time, and a long soak test is what caught it.

Code on GitHub

edge-engine

An AI analyst paired with a Python pricing engine that prices sports bets the way a trading desk would, with the analyst held to a 15-rule spec. Every bet is graded on process instead of outcome, so a well-reasoned bet that loses still counts as a good decision and a lucky win does not. Building it taught me to judge a decision by the reasoning behind it, not just by how it turned out.

Code on GitHub

Steth-o-Beat

A $2.25 stethoscope that uses a machine learning model to classify breathing sounds, with 360+ devices now in use across 16 clinics in India. The model is TensorFlow's speech_commands example retrained on respiratory sound labels and converted to TensorFlow Lite. It taught me that a medical device has to be cheap and simple before clinics will actually use it.
